# Exercice 1 : Les trois cadences

## 1. Duree d'une image au dixieme de milliseconde

- A 72 Hz : 1000 / 72 = 13.9 ms
- A 90 Hz : 1000 / 90 = 11.1 ms
- A 120 Hz : 1000 / 120 = 8.3 ms

## 2. Temps restant pour le code applicatif

En retirant les 8.0 ms prises par le materiel (capteurs, transmission, composition et affichage) :

- A 72 Hz : 13.9 ms - 8.0 ms = 5.9 ms
- A 90 Hz : 11.1 ms - 8.0 ms = 3.1 ms
- A 120 Hz : 8.3 ms - 8.0 ms = 0.3 ms

## 3. Les trois nombres

Les temps restants pour le code sont :
- 5.9 ms (a 72 Hz)
- 3.1 ms (a 90 Hz)
- 0.3 ms (a 120 Hz)
